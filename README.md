🎬 CineBooking

A simple Movie Ticket Booking System built using Python and Tkinter.
The application provides a graphical interface where users can select movies, book available seats, and view their booking details and total price.

✨ Features

* 👤 User name-based login
* 🎥 Movie selection with show timings and ticket prices
* 💺 Seat selection and booking
* 🔴 Real-time indication of booked seats
* 🎟️ View all booked tickets
* 💰 Automatic calculation of total booking price
* 🔄 Reset booking system
* 🖥️ Simple and user-friendly GUI

🛠️ Technologies Used

* Python 3
* Tkinter – Graphical User Interface

🚀 How to Run

1. Clone the repository

git clone https://github.com/thisc0ffeeisfunny/CineBooking.git

2. Open the project directory

cd CineBooking

3. Run the application

python cinebooking.py

Note: Tkinter is included with most standard Python installations. If it is not available on your system, install the appropriate Tkinter package for your operating system.
